# MiniMax H3 三段拼接工作流 · 通用提示词填写方法（不绑定任何剧情）

> 适用于任何角色 / 场景 / 剧情。工作流 = 3 段 × 5 秒，提示词一共 6 个框：
> 3 个「全局提示词」 + 3 个「段提示词」。

---

## 一、一句话总原则

**全局写“全程不变的”，段里写“这一段动的”，锚点句照抄不换词。**

---

## 二、全局框 ×3（三段复制同一套，只填“不变”的设定）

1. **场景**：地点 + 风格 + 光线
   例：写实室内桌面 / 赛博街道夜景 / 森林湖边晨光
2. **角色**：形象来源（第一段用 `<Picture 2>` 引用角色图）+ 体型比例（与画面中某参照物等高，约 X cm）+ 手持道具（始终不离手）
3. **机位（可选）**：需要稳定画面时写「固定机位远景全景，整个场景完整入镜」；不需要就不写，运镜可以自由设计
4. **画面白名单（可选）**：想避免模型乱加物体时，列清楚允许出现的物体；不需要可省略
5. **音频（可选）**：需要特定音效（如动作/碰撞音效、无台词、无BGM）就写清楚；不需要可省略

## 三、段框 ×3（每段只写本段动作，按时间轴切）

| 段 | 职责 | 写作结构 |
|---|---|---|
| 第一段 | 出场 / 开始 | 从哪出现 → 小动作 → 主要登场动作 → 收势 |
| 第二段 | 过程 | 承接上一段 → 主要动作 / 冲突 → 结果 |
| 第三段 | 收尾 | 最后的动作 → 面向镜头 / 定格 |

规则：
- 每段只写本时间窗（5 秒）内的事，不写后面的剧情。
- 第二三段开头用「接着 / 随后」承接上一段结尾状态。

## 四、必抄锚点句（通用占位）

| 位置 | 锚点句 |
|---|---|
| 第二三段第一句 | 「视频第一帧必须与给定首帧画面完全一致，【角色】必须始终在场、不能消失」 |
| 每段开头 | 「固定机位，镜头完全保持不动：不推近、不聚焦、不变焦」 |
| 每段结尾 | 「全程保持【体型比例】，不能变大；【道具】始终握在手中」 |
| 全局 | 加上「角色不说话、无台词；音频只要动作音效，不要背景音乐」 |

## 五、一致性四道保障（不需要观众懂，但说明为什么这么写）

1. 全局三段完全相同 → 世界设定统一
2. 锚点句逐字复用 → 关键约束不被换说法稀释
3. 首帧锁定 → 第二三段第一帧 = 上一段最后一帧，画面物理连续
4. 同一种子 + 同一参考图 → 角色形象不漂移

## 六、写完后自查（30 秒）

- [ ] 三个全局是否完全相同？
- [ ] 角色 / 道具 / 体型在每段措辞是否一致？
- [ ] 每段动作是否只在本时间窗？
- [ ] 第二三段第一句是否“首帧必须一致 + 角色在场”？
- [ ] 机位句、白名单、无台词音效是否每段都带？
