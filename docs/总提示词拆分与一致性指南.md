# 从总提示词到六个提示词框：拆分与一致性指南

> 适用：MiniMax H3 三段拼接工作流（第一段 r2v + 第二、三段 i2v，一次 Queue 全自动）。
> 六个提示词框 = 3 个“全局提示词” + 3 个“段提示词”。

---

## 一、先写一条“总提示词”（Master Prompt）

不要直接往框里塞，先完整写一条描述整条 15 秒视频的总提示词，按下面五块组织：

```
【场景/风格】地点、光线、氛围、画面质感
【角色】形象来源（<Picture 2>）、体型比例、手持道具
【时间轴动作】0-5秒：……；5-10秒：……；10-15秒：……
【相机与画面】固定机位、全景构图、禁止事项
【音频】动作/碰撞音效、无台词、无BGM
```

示例（可直接当模板）：

> 写实室内电脑桌面，照片质感，环境光柔和，粉色窗帘背景。
> 角色是<Picture 2>的Q版【角色名】，身高与画面左侧巧克力棒饼干盒完全等高（约10厘米），始终很小，手中始终握着【白色小剑】。
> 0-5秒：从显示器屏幕内探头、试探行走、慢慢钻出屏幕、跳到桌面站定；
> 5-10秒：把饼干盒当BOSS，握剑蓄力冲刺，跳踢踹翻饼干盒，零食散落，帅气落地；
> 10-15秒：面向镜头炫耀邀功，叉腰挺胸、举剑示意、傲娇扭头，定格收尾。
> 固定机位远景全景，整个桌面完整入镜，禁止推近/聚焦/特写/变焦，禁止镜头跟随角色。
> 桌面物品白名单：显示器、键盘、鼠标、笔记本、白色主机、粉色篮子、饼干盒、角色本人；禁止任何玩偶/玩具/额外人偶。
> 音频只要动作与碰撞音效（脚步、落地、碰撞、哗啦、按键、挥剑），角色不说话无台词，无背景音乐。

## 二、拆分规则：先“抽全局”，再“切动作”

### 第 1 步：把“全程不变”的部分抽成全局提示词（三段完全复制同一套）

从总提示词里挑出这些**全程不变**的内容 → 填进三个 Director 的 `global_prompt`（三段一字不差）：

- 场景/风格/灯光/构图
- 角色形象来源 + 体型比例 + 手持道具
- 相机铁律（固定机位全景、禁止推近/聚焦/变焦）
- 物品白名单
- 音频规则 + 无台词

> **一致性第一保障：全局三段完全相同。** 只要全局一致，模型拿到的是同一套“世界设定”。

### 第 2 步：把“动作时间轴”按 0-5 / 5-10 / 10-15 切成三个段提示词

- 第一段（r2v）：总提示词的 0-5 秒动作 + 参考图引用（`<Picture 1>` 场景、`<Picture 2>` 角色）
- 第二段（i2v）：5-10 秒动作
- 第三段（i2v）：10-15 秒动作

拆分时注意：

1. **每段只放本时间窗的动作**，别把后面的剧情提前写。
2. **段与段之间要“承上启下”**：第二段开头写“接着/随后”，暗示承接第一段结尾状态（视觉上由首帧锁定自动保证，文字上再强化一次）。
3. **每段结尾给一个明确的“完成状态”**（如：站定、落地、定格），方便下一段接住。

### 第 3 步：把“一致性锚点”嵌进每个段提示词

每段提示词不复制全文，但必须重复以下**固定短锚点**（与全局措辞逐字一致）：

| 锚点 | 统一写法 |
|---|---|
| 体型 | `与饼干盒完全等高（约10厘米），不能变大` |
| 道具 | `【白色小剑】始终握在手中、不离手` |
| 机位（i2v 段） | `固定机位，镜头完全保持不动：不推近、不聚焦、不变焦，全景构图完整展示整个桌面` |
| 锁帧（i2v 段，放第一句） | `视频第一帧必须与给定首帧画面完全一致，角色必须始终在场、不能消失` |
| 白名单 | `桌面物品白名单：【同全局】` |
| 音频 | `只保留动作与碰撞音效，角色不说话无台词，不要背景音乐` |

> **一致性第二保障：锚点短语逐字复用。** 模型对短固定句的遵循度远高于“大意相同”的换说法。

## 三、六槽位填写模板（最终形态）

### 全局 ×3（三段完全一致）

```
固定机位远景全景：镜头从第一帧到最后一帧完全静止，整个桌面（显示器、键盘、巧克力棒饼干盒）完整充满画面，
背景物体位置全程不变，禁止推近、禁止聚焦、禁止特写、禁止变焦、禁止镜头跟随角色。
桌面物品白名单：桌面上只允许出现显示器、键盘、鼠标、笔记本电脑、白色主机、粉色小篮子、巧克力棒饼干盒和角色本人；
禁止出现任何其他物品，尤其禁止任何玩偶、小熊、泰迪熊、毛绒玩具、人偶、吉祥物、装饰品。
场景完全复用<Picture 1>的灯光与布局，<Picture 1>中电脑屏幕上的壁纸女孩只是背景装饰，禁止作为角色形象。
角色必须是<Picture 2>中的Q版【角色名】，发型、服饰、五官完全以<Picture 2>为准；
角色身高与画面左侧巧克力棒饼干盒完全等高（约10厘米），始终很小、远离镜头，明显小于显示器、键盘和鼠标；
【白色小剑】始终握在手中、不离手，比例迷你。
背景保持照片写实质感，Q版角色与写实实景自然融合，动作细腻连贯，无穿模，细节清晰，画面稳定，无镜头晃动。
角色不说话，没有任何台词，无人声对白。
音频要求：全片只保留动作与碰撞音效，不要任何背景音乐（无BGM）、不要音乐、不要环境音乐。
```

### 第一段（0-5 秒）＝ 锁帧句（无）＋ 相机锚点 ＋ 白名单锚点 ＋ 0-5 秒动作 ＋ 锚点

```
固定机位远景全景：镜头完全静止，整个桌面始终完整入镜，禁止推近、聚焦、特写、变焦。
桌面物品白名单：【同全局】。
角色以小小身影首先出现在【出场位置】：
先【小动作1】→ 再【小动作2】→ 然后【主要动作】→ 最后【收势】。
全程保持与饼干盒等高的小体型，绝对不能放大；角色形象必须与<Picture 2>一致，不得变成壁纸女孩；
【白色小剑】始终握在手中，不离手。
音效：只保留动作音效（脚步声、落地、摩擦、挥剑），角色不说话，无台词，不要背景音乐。
```

### 第二/三段（i2v）＝ 锁帧句（第一句）＋ 相机锚点 ＋ 白名单锚点 ＋ 本段动作 ＋ 锚点

```
视频第一帧必须与给定首帧画面完全一致，角色必须始终在场、不能消失、不能隐身。
固定机位，镜头完全保持不动：不推近、不拉近、不聚焦、不变焦、不移动，
全景构图完整展示整个桌面，视角始终与首帧一致，只靠角色动作推进。
桌面物品白名单：【同全局】。
中间过程：【本段动作：先→再→最后收尾，并写“接着/随后”承接上一段】。
全程保持与饼干盒等高的小体型（约10厘米），不能变大；【白色小剑】始终握在手中、不离手。
音效：只保留动作与碰撞音效，角色不说话，无台词，不要背景音乐。
```

## 四、一致性由四道机制共同保证

| 机制 | 作用 | 在哪配置 |
|---|---|---|
| ① 全局三段相同 | 世界设定（角色/场景/机位/道具）统一 | 三个 Director 的 global_prompt |
| ② 锚点短语逐字复用 | 体型、道具、机位、锁帧等关键约束不被换说法稀释 | 三个段提示词 |
| ③ 首帧锁定（i2v 段） | 第二三段第一帧 = 上一段最后一帧，画面物理连续 | 工作流自动（ImageFromBatch 取第123帧） |
| ④ 同一种子 + 同一参考图 | 减少随机漂移；角色形象锁定于 <Picture 2> | 三个 Director 的 seed 相同（已配置） |

> 改提示词时，**只动段提示词的动作部分**，锚点和全局不要改；想改角色/场景/机位/道具时，**同时改三段全局**（保持相同），再把对应锚点同步到三段。

## 五、写完后 30 秒自查清单

- [ ] 三个全局提示词是否完全一致？
- [ ] 角色名、体型、道具在全局和每个段里措辞是否逐字一致？
- [ ] 每段动作是否严格落在本时间窗（0-5 / 5-10 / 10-15）？
- [ ] 第二、三段第一句是否都是“首帧必须一致 + 角色始终在场”？
- [ ] 相机铁律是否出现在全局和每个段？
- [ ] 白名单、无台词、音效规则是否每段都带？
- [ ] 段落边界是否有“接着/随后”承接词？

全部打勾 → 提交 Queue。跑完抽查 3 个关键帧（每段中间一帧 + 结尾帧），用识图或肉眼确认角色/场景/机位没有漂移。
