# 参数详解与推荐配置（MiniMax H3 Chain Director）

链式导演台会把长视频拆成 N 段逐段生成，因此**下面的采样参数都是「每一段内部」的配置**，不是整条视频的配置。例如 60 秒 ÷ 10 秒每段 = 6 段，采样步数填 4 意味着 6 段各自跑一次 4 步采样。

## 六项核心参数速查

| 参数 | 推荐值 | 一句话作用 |
|---|---|---|
| `ref_video_fps`（参考视频帧率） | `0` | 接参考视频时：0 = 自动等比切分；填真实帧率 = 精确按秒切 |
| `自动锚点` | 勾选（True） | 自动往每段提示词补「首帧锁定 / 体型一致 / 参考图一致」锚点句 |
| `采样步数` | `4`（turbo LoRA）/ `8`（画质优先） | 每一段内部的扩散采样步数 |
| `采样器` | `er_sde` | MiniMax H3 + turbo LoRA 的标准采样器 |
| `调度器` | `simple` | 与 er_sde / turbo LoRA 配套的标准调度器 |
| `引导强度CFG` | `1.0`（turbo LoRA） | 提示词对生成结果的控制强度 |

## 1. ref_video_fps（参考视频帧率）

- 类型：整数，范围 `0~240`，默认 `0`。
- 作用：只在给节点接了 `ref_video`（参考视频）时才有意义，决定参考视频如何按段切分：
  - `0` = 自动等比切分：不关心视频实际 fps，按帧数比例把参考视频平均分给每一段（最通用，推荐）。
  - 填真实帧率（如 `30`）= 精确按秒切：每段取「段长秒数 × 帧率」的帧。
- 选择建议：不知道参考视频 fps、或视频有变速/补帧，用 `0`；需要严格“每秒对应”时填真实 fps。
- 注意：**不接 ref_video 时保持 0 即可**，不影响任何生成。

## 2. 自动锚点（auto_anchor）

- 类型：开关，默认勾选。
- 作用：勾选后节点会自动往每一段提示词后面追加一组“锁一致性”的锚点句，例如：首帧必须与上一段最后一帧完全一致、角色体型/服装/发色以参考图为准且全程不变、场景物体位置不漂移。
- 选择建议：默认保持勾选。只有当你已经在提示词里自己写了非常完整的锚点、且想完全自己控制措辞时才取消。
- 副作用：锚点句偶尔会与你的提示词内容重复，通常无害；若觉得角色被“锁”得太死（动作放不开），可取消勾选后自己写锚点句。

## 3. 采样步数（steps）

- 类型：整数，范围 `1~100`，默认 `4`。
- 含义：**每一段**内部的扩散采样步数。整条视频总采样量 = 段数 × 每段步数。
- 选择建议：
  - `4`：接了 turbo LoRA（lightx2v 4step）时推荐；速度快，观感接近 LoRA 宣传效果。
  - `8`：画质/稳定性更好，耗时约为 4 步的 1.8~2 倍。
  - 其他值：不接 turbo LoRA、用原版模型时，通常 `10~30` 步。
- 注意：`4` 步只对接了 turbo LoRA 的模型有意义；没接 LoRA 却用 4 步会欠采样（画面糊、马赛克）。

## 4. 采样器（sampler）

- 类型：下拉框（44 个选项），默认 `er_sde`。
- 作用：控制扩散去噪的数值求解方式，不同采样器的收敛速度和画风不同。
- 选择建议：MiniMax H3 + turbo LoRA 用 **er_sde**；不接 LoRA 时可试 `dpmpp_2m_sde` / `euler_ancestral`。
- 报错提示：如果下拉框里没有 `er_sde`，说明 ComfyUI 版本过旧，请升级到 ≥ 0.30。

## 5. 调度器（scheduler）

- 类型：下拉框，默认 `simple`。
- 作用：控制每一步的噪声调度曲线。
- 选择建议：配合 `er_sde` + turbo LoRA 用 **simple**，一般不需要改。
- 调试：画面过曝/发灰时可试 `karras` / `exponential`，但 turbo LoRA 下通常 `simple` 最稳。

## 6. 引导强度CFG（cfg）

- 类型：小数，范围 `0.0~10.0`，默认 `1.0`。
- 含义：提示词对画面的控制强度。越大越“听提示词”，但过大容易过饱和、产生伪影。
- 选择建议：
  - turbo LoRA：`1.0`（通常 `0.8~1.5` 区间内微调）。
  - 不接 LoRA 的原版模型：`3~6`。
- 常见问题：CFG 太高 + 4 步 = 画面发糊/颜色过艳/抽搐；CFG 太低 = 画面不跟随提示词。

## 常见场景推荐配置

| 场景 | 分辨率 | 分段 | 步数 | 采样器/调度器 | CFG |
|---|---|---|---|---|---|
| 快速验证 | 480p | 5s/段 | 4 | er_sde + simple | 1.0 |
| 出片（速度优先） | 720p | 5s/段 | 4 | er_sde + simple | 1.0 |
| 出片（画质优先） | 720p | 5s/段 | 8 | er_sde + simple | 1.0 |
| 1080p 长片 | 1080p | 5s/段 | 4~8 | er_sde + simple | 1.0 |

## 常见报错排查

### 打开老工作流报「输入超出范围 / 无效输入 / 输入值类型错误」

- 原因：工作流是用**旧版节点**保存的；节点升级后新增了 `ref_video_fps` 参数，导致老工作流参数整体错位（典型表现：采样步数格子显示 `er_sde`、CFG 显示超大数字）。
- 修复：手动把这几项改回推荐值再另存：`ref_video_fps=0`、自动锚点=勾选、采样步数=`4`、采样器=`er_sde`、调度器=`simple`、CFG=`1.0`。

### 运行报 ModuleNotFoundError: No module named 'sageattention'

- 原因：工作流里挂了两个 `Patch Sage Attention (KJ)` 节点，但当前 ComfyUI 环境没有安装 `sageattention`。
- 修复：右键两个 SageAttention 节点选 **Bypass**（临时跳过），或按 README 的说明安装 `sageattention==1.0.6`。
